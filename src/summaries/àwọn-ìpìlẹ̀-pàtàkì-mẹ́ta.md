      <h2 class="text-3xl font-normal leading-tight text-white sm:text-4xl border-b border-[#24211e] pb-5 text-center">
        Ìpìlẹ̀ Pàtàkì Kejì
      </h2>

      <p class="text-lg leading-relaxed sm:text-xl">
        Ẹ̀rí láti inú Sunnah ni hadith olókìkí Jibreel, tí Umar bin Al-Khattaab ròyìn rẹ̀. Ó sọ pé:
      </p>

      <div class="bg-[#24211e] border border-[#332f2b] p-6 sm:p-8 rounded-lg space-y-6">

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          “Ní ọjọ́ kan, a jókòó pẹ̀lú Anọ́bí Muhammad ﷺ, nígbà tí ọkùnrin kan farahàn sí wa. Aṣọ rẹ̀ funfun gan-an, irun rẹ̀ sì dúdú gan-an.
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          A kò rí àmì ìrìn-àjò kankan lára rẹ̀, kò sì sí ẹnikẹ́ni nínú wa tí ó mọ̀ ọ́n. Ó jókòó níwájú Anọ́bí ﷺ, ó so eékún rẹ̀ pọ̀ mọ́ eékún Anọ́bí ﷺ, ó sì gbé àtẹ́lẹwọ́ rẹ̀ sí orí itan rẹ̀, ó sì wí pé:
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          ‘Ìwọ Muhammad, sọ fún mi nípa Islam.’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Ó dáhùn pé: ‘Ó túmọ̀ sí pé kí o jẹ́rìí pé kò sí ọlọ́run kankan tí ó lẹ́tọ̀ọ́ sí ìjọsìn àyàfi Allah, àti pé Muhammad ni Òjíṣẹ́ Allah. Kí o sì máa ṣe Salaah, kí o máa fúnni ní Zakaah, kí o gba ààwẹ̀ ní oṣù Ramadaan, kí o sì ṣe Hajj sí Ilé Allah bí o bá lè ṣe é.’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Ó wí pé: ‘Òótọ́ ni o sọ.’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Ẹnu yà wá pé ó béèrè lọ́wọ́ rẹ̀, lẹ́yìn náà ó sì sọ fún un pé òótọ́ ni ohun tí ó sọ.
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Ó tún wí pé: ‘Sọ fún mi nípa Iman.’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Ó dáhùn pé: ‘Ó túmọ̀ sí pé kí o gba Allah gbọ́, àwọn Malaika Rẹ̀, àwọn Ìwé Rẹ̀ tí Ó sọ̀kalẹ̀, àwọn Òjíṣẹ́ Rẹ̀, Ọjọ́ Ìkẹyìn, àti kí o gba Al-Qadar gbọ́, rere àti búburú rẹ̀.’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Ó wí pé: ‘Òótọ́ ni o sọ.’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Ó tún wí pé: ‘Sọ fún mi nípa Ihsan.’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Ó dáhùn pé: ‘Ó túmọ̀ sí pé kí o jọ́sìn fún Allah bí ẹni pé o ń rí I. Bí ó tilẹ̀ jẹ́ pé o kò rí I, dájúdájú Ó ń rí ọ.’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Ó tún wí pé: ‘Sọ fún mi nípa Wákàtí Ìkẹyìn.’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Ó dáhùn pé: ‘Ẹni tí a ń béèrè lọ́wọ́ rẹ̀ kò ní ìmọ̀ sí i nípa rẹ̀ ju ẹni tí ó ń béèrè lọ́wọ́ rẹ̀ lọ.’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Ó wí pé: ‘Nígbà náà, sọ fún mi nípa àwọn àmì rẹ̀.’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Ó dáhùn pé: ‘Ó máa ṣẹlẹ̀ nígbà tí ìránṣẹ́bìnrin bá bí ìyá rẹ̀ obìnrin, àti nígbà tí àwọn olùṣọ́ àgùntàn tí wọ́n jẹ́ aláìwọ bàtà, aláìní àti onírẹ̀lẹ̀ yóò máa bá ara wọn díje ní kíkọ́ àwọn ilé gíga.’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Lẹ́yìn náà, ọkùnrin náà lọ, a sì dúró níbẹ̀ fún ìgbà díẹ̀.
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Lẹ́yìn náà, Anọ́bí ﷺ béèrè pé: ‘Ìwọ Umar, ṣé o mọ ẹni tí ó béèrè àwọn ìbéèrè wọ̀nyí?’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Mo dáhùn pé: ‘Allah àti Òjíṣẹ́ Rẹ̀ ló mọ̀ jùlọ.’
        </p>

        <p class="text-lg sm:text-xl leading-relaxed text-[#ECE8EF]">
          Ó wí pé: ‘Jibreel ni. Ó wá sọ́dọ̀ yín láti kọ́ yín ní ẹ̀sìn yín.’”
        </p>

<!-- Script to handle reveal on scroll -->
<script>
  document.addEventListener("DOMContentLoaded", function () {
    const observerOptions = {
      root: null,
      rootMargin: "0px",
      threshold: 0.1
    };

    const observer = new IntersectionObserver((entries, observer) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          entry.target.classList.add("is-visible");
          observer.unobserve(entry.target);
        }
      });
    }, observerOptions);

    const revealElements = document.querySelectorAll(".reveal-on-scroll");
    revealElements.forEach(el => observer.observe(el));
  });
</script>
