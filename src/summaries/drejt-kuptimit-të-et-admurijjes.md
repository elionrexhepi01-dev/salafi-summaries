        <span class="text-sm font-mono text-[#d6b278] bg-[#1c1a18] px-3 py-1 rounded border border-[#332f2b]">Pohim i Tepruar</span>

        E tepruan në pohim deri në atë pikë sa i krahasuan Cilësitë e Allahut me krijesat, duke lënë pas dore mohimin thelbësor të ngjashmërisë (<e>Tamthīl</e>).
      </p>
    </div>

    <!-- Mu'attilah Overview -->
    <div class="bg-[#24211e] border border-[#24211e] p-6 rounded-lg space-y-4">

        <span class="text-sm font-mono text-[#d6b278] bg-[#1c1a18] px-3 py-1 rounded border border-[#332f2b]">Mohim i Tepruar</span>
      </h3>
      <p class="text-base text-[#B3ADB9]">
        E tepruan në mohim nga frika e përngjasimit të Allahut me krijesat, duke e zhveshur kështu Allahun nga Emrat dhe Cilësitë e Tij reale. Kjo kategori kryesore ndahet në rryma të ndryshme:
      </p>

      <div class="space-y-3 pt-2 border-t border-[#332f2b]">
        <div class="bg-[#1c1a18] p-4 rounded border border-[#2a2724]">

          <p class="text-sm sm:text-base text-[#B3ADB9]">Pohojnë Emrat dhe një pjesë të Cilësive, por i refuzojnë ose i interpretojnë ndryshe (<e>Ta’wīl</e>) të tjerat, duke besuar se arsyeja e tyre bie në kundërshtim me dëshmitë tekstuale të drejtpërdrejta.</p>
        </div>

        <div class="bg-[#1c1a18] p-4 rounded border border-[#2a2724]">
          <strong class="block mb-1 text-base text-white sm:text-lg">El-Mu‘tazilah (Mu‘tezilitët):</strong>
          <p class="text-sm sm:text-base text-[#B3ADB9]">Pohojnë Emrat vetëm si emra të përveçëm, të zhveshur nga Cilësitë që nënkuptohen prej tyre (p.sh., duke pretenduar se Ai është “i Dijshëm pa dije” ose “i Fuqishëm pa fuqi”).</p>
        </div>

        <div class="bg-[#1c1a18] p-4 rounded border border-[#2a2724]">

          <p class="text-sm sm:text-base text-[#B3ADB9]">Mohojnë si Emrat, ashtu edhe Cilësitë. Disa bien në paradokse të skajshme duke mohuar njëkohësisht edhe pohimin, edhe mohimin—duke thënë se Ai është “as ekzistues, as joekzistues, as i gjallë, as i vdekur.”</p>

<!-- Script to handle reveal on scroll -->

<script>
  document.addEventListener("DOMContentLoaded", function () {
    const observerOptions = {
      root: null,
      rootMargin: "0px",
      threshold: 0.1
    };

    const observer = new IntersectionObserver((entries, observer) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          entry.target.classList.add("is-visible");
          observer.unobserve(entry.target);
        }
      });
    }, observerOptions);

    const revealElements = document.querySelectorAll(".reveal-on-scroll");
    revealElements.forEach(el => observer.observe(el));
  });
</script>
